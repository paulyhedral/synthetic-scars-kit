# Security Policy

## Supported Versions

This repo has no tagged releases yet. Once releases begin, only the most recent release will be
supported with security updates.

## Reporting a Vulnerability

Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/paulyhedral/synthetic-scars-kit/security/advisories/new)
rather than opening a public issue. You should expect an initial response within a few days.
